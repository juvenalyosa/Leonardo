# Leonardo screenshots for the manuscript

Place real PNG screenshots here before submission.  Do not use mockups for the
BMC manuscript.

Required screenshots:

- `main_window.png`: PyMOL with the Leonardo launcher/menu visible.
- `workflow_window.png`: one representative module window with protein/ligand or
  object selectors visible, preferably interaction analysis or pocket docking.
- `result_report.png`: a result popup/report window showing parsed outputs,
  contacts, docking poses or task-monitor status.

Capture guidance:

- Use a light/gray UI theme.
- Use a desktop-size window, at least 1600 px wide.
- Avoid overlapping dialogs, clipped labels or hidden object names.
- Keep protein and ligand object names visible where the workflow depends on
  object selection.
- Save lossless PNG files.
